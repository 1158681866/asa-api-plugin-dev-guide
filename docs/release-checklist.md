# 发布检查清单

发布前逐项确认。

## 代码

- [ ] 没有废弃 Hook。
- [ ] 没有废弃配置字段。
- [ ] 没有旧扫描/timer 残留。
- [ ] 高风险调用有理由、范围限制或已移除。
- [ ] Debug 日志受配置控制。
- [ ] 玩家可见文本没有硬编码到难以修改的位置。
- [ ] 注册的命令、Hook、timer 和后台线程在重载/卸载时能正确结束；ASA API 2.03 及以后的命令/命令回调由 API 自动清理，`Plugin_Unload()` 不重复手动调用命令 `Remove*`。
- [ ] 正式聊天命令使用 `AddChatCommand`，未用普通聊天回调手工解析代替。
- [ ] 动态重载命令别名不会在当前聊天命令回调栈内直接修改命令容器。

## 配置

- [ ] 默认配置能加载。
- [ ] 数值范围会 clamp 或报错。
- [ ] 字符串模式会归一化。
- [ ] 文档里的配置和包内配置一致。

## 测试

- [ ] Release 编译通过。
- [ ] core tests 通过。
- [ ] 本地 `build/package/<Plugin>` 测试目录已刷新。
- [ ] 本地测试目录未因精简 ZIP 删除 `README.md`、`CHANGELOG.md` 副本或覆盖本地配置。
- [ ] 已实际枚举 `build/package/` 顶层；默认只显示 `<Plugin>/` 本地测试目录与同级 Release ZIP，没有额外测试 ZIP 或长期 `release/` 目录。
- [ ] `build/` 下不存在打包或校验遗留的 `stage` / `staging` 目录、一次性验证 ZIP 或重定向日志。
- [ ] 正式发布 DLL 来自本次 `Release|x64` 重建；若复用既有 DLL，新鲜度门禁已覆盖源码、`.sln/.vcxproj` 和项目自定义 `.props/.targets`。
- [ ] 最终 ZIP 内 DLL 的 `Format: RSDS` 未泄露盘符、UNC、用户目录等本机 PDB 路径，ZIP staging 的已知本机路径扫描无命中。
- [ ] DLL 时间是本次构建时间。

## 文档

- [ ] 源码仓库里的 README / 项目文档说明当前真实逻辑。
- [ ] 中文配置说明完整。
- [ ] 测试流程可操作。
- [ ] 已知风险写清楚。

## 最终对外 ZIP 内容

- [ ] ZIP 内包含 DLL、`PluginInfo.json`、`config.json`、`config说明.json`。
- [ ] `README.md`、`CHANGELOG.md` 等开发者文档未进入 ZIP，但源码树和本地测试目录中的文件未被删除。
- [ ] 除标准四类文件外的每个额外文件都确属运行必需，并已在源码文档中说明依赖原因。
- [ ] ZIP 通过临时 staging、显式条目白名单或等价流程生成，验证结果不依赖清空本地测试目录。
- [ ] 临时 staging 的递归清理有项目包目录边界检查，并由 `try/finally` 覆盖成功、失败和校验异常路径。

## 上服测试

- [ ] 插件加载日志正常。
- [ ] 至少完成一次插件卸载和重新加载，过程中无 crash、卡死或命令残留。
- [ ] 命令能保存选择。
- [ ] 第二名玩家看不到其他玩家输入的命令文本。
- [ ] 关键 Hook 按预期触发。
- [ ] 功能实际生效。
- [ ] 无新增红字。
- [ ] 无 crash。
- [ ] 无服务器无响应/断联。

## 回滚

- [ ] 保留上一版可用 DLL。
- [ ] 记录本版 DLL 时间。
- [ ] 记录本版配置。
