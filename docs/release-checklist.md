# 发布检查清单

发布前逐项确认。

## 代码

- [ ] 没有废弃 Hook。
- [ ] 没有废弃配置字段。
- [ ] 没有旧扫描/timer 残留。
- [ ] 高风险调用有理由、范围限制或已移除。
- [ ] Debug 日志受配置控制。
- [ ] 玩家可见文本没有硬编码到难以修改的位置。
- [ ] 注册的命令、Hook、timer 在重载/卸载时能清理。

## 配置

- [ ] 默认配置能加载。
- [ ] 数值范围会 clamp 或报错。
- [ ] 字符串模式会归一化。
- [ ] 文档里的配置和包内配置一致。

## 测试

- [ ] Release 编译通过。
- [ ] core tests 通过。
- [ ] 包目录已刷新。
- [ ] DLL 时间是最新。

## 文档

- [ ] README 说明当前真实逻辑。
- [ ] 中文配置说明完整。
- [ ] 测试流程可操作。
- [ ] 已知风险写清楚。

## 上服测试

- [ ] 插件加载日志正常。
- [ ] 命令能保存选择。
- [ ] 关键 Hook 按预期触发。
- [ ] 功能实际生效。
- [ ] 无新增红字。
- [ ] 无 crash。
- [ ] 无服务器无响应/断联。

## 回滚

- [ ] 保留上一版可用 DLL。
- [ ] 记录本版 DLL 时间。
- [ ] 记录本版配置。
