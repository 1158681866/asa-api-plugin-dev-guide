# 排错手册

## 崩服有 crash 栈

收集：

- `crashcallstack.txt`
- 最新 `ArkApi_*.log`
- 同时间段游戏日志
- 插件 DLL 时间
- 插件配置
- ASA 服务端版本
- AsaApi 版本

看栈位置：

- 插件加载阶段：Hook 签名 / offset / SDK 版本
- 命令阶段：参数解析、权限判断、目标对象、回执发送
- Timer 阶段：重试条件、弱引用、对象失效
- 事件 Hook 阶段：字段读写、事件链、其他插件交互
- 资源阶段：类加载、库存、容器、资产路径

## 无 crash 无响应

无 crash 最难排。要加阶段日志：

```text
命令#15 阶段=收到命令
命令#15 阶段=权限检查前
命令#15 阶段=权限检查后
命令#15 阶段=保存选择前
命令#15 阶段=保存选择后
```

无响应后只看最后一条日志。

## 一次只测一个变量

不要同时改多个风险点。隔离顺序：

1. 关闭命令回执
2. 跳过可选目标解析
3. 关闭可选字段写入
4. 关闭通知
5. 关闭资源/库存相关逻辑
6. 移除可疑 native call

## 远程服务器

如果开发机不是服务器：

- 不要说“修好了”
- 说“本地包已准备好”
- 明确让用户看哪些日志
- 让用户确认 DLL 时间

## 判断旧 DLL

如果日志仍出现已删除的旧文案或旧阶段名，优先怀疑服务器没有换到新 DLL。
