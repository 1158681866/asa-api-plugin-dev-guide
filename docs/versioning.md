# 版本策略

## 语义化版本

推荐使用：

```text
MAJOR.MINOR.PATCH
```

- `MAJOR`：破坏性配置变更、重构主链路、删除兼容行为。
- `MINOR`：新增功能、配置项、可选能力。
- `PATCH`：修 bug、文档补充、稳定性小改。

## 插件版本记录

每次发布至少记录：

- 版本号
- DLL 时间
- 配置变化
- Hook 变化
- 风险点变化
- 上服测试结果

## 配置兼容

新增配置项时：

- 代码有默认值。
- 旧配置缺字段也能加载。
- 文档说明默认行为。

删除配置项时：

- 文档明确废弃。
- 代码不再读取。
- 包内默认配置移除。

## 发布包命名

推荐：

```text
PluginName-v0.1.0.zip
PluginName-v0.1.1-hotfix.zip
```

测试包可以带时间：

```text
PluginName-test-20260623-1720.zip
```
